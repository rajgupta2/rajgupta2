### 📌 Featured Projects

**[SkillHub](https://skillhub-student.vercel.app)** - **A Learning Management Platform**      
- Developed a full-stack learning platform for resource/file sharing, article publishing with secure role-based authentication.   
- Integrated **Amazon S3** for file storage and management of learning resources.   
- **Stack:** Next.js · Express.js · Prisma ORM · PostgreSQL · AWS · Tailwind CSS  

**[StudyStudent](https://github.com/rajgupta2/StudyStudent)** - **An Educational Platform**    
- Developed an educational platform enabling students to access tutorials, study materials, and submit assignments.    
- Built an **admin dashboard** for managing student records, reviewing submissions, and posting resources and announcements.    
- Integrated **Google Sign-In and Recaptcha API** to strengthen authentication and application security.    
- **Stack:** Node.js · Express · EJS · Passport.js · MongoDB Atlas

**[Terrform AWS Infrastructure Automation](https://github.com/rajgupta2/tech_eazy_devops_rajgupta2)**     
- Terraform-based IaC provisioning environment-specific (dev/prod) AWS infrastructure with EC2, S3-backed log storage, CloudWatch log streaming, and SNS-based alerting.    
- Fully automated via GitHub Actions (deploy, destroy, and shared-resource cleanup workflows) with remote Terraform state managed in S3.   
- **Stack:** Terraform · AWS (EC2, S3, CloudWatch, SNS, IAM) · GitHub Actions
